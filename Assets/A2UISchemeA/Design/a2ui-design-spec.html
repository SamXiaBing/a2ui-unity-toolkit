1. Figma 图层命名规范

所有图层名必须与下表一致。代码侧（USS class + C# Mapper）按此命名匹配样式。

核心规则：
  • Frame 名 = Surface/{surfaceId}（如 Surface/media）
  • 每个组件节点名 = A2UI JSONL 里的 id 值（如 root、col、title）
  • 节点上标注组件类型，格式：{id} / {Type}（如 title / Text）
  • Text 子节点标注 usageHint：title / Text:h2
  • Button 标注 primary：playBtn / Button:primary
  • Card 内子容器标注方向：col / Column 或 row / Row
